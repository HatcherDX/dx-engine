Welcome to the Hatcher IDE documentation.

This section is prose-first: each page is written to read well on its own, with
interactive widgets embedded progressively over time. Phase 1 ships
documentation only — no widgets yet.

## What is Hatcher?

Hatcher is a visual builder IDE for the AI era. Its core — the host, the
`.uicr` format and SDK, the component substrate, the Web Component output, and
the Code, Gen, and Time Graph HATs — is open source under the MIT license.
Whatever you build is yours and portable: delete the builder and your code
still builds.
